miniRaft — a Raft-replicated vector store

Three replicas running a hand-written Raft consensus engine, each building its own HNSW index from the replicated log. This is the real engine — the same raft.js and hnsw.js that run on the server — executing in your browser over a deterministic simulated network. Break it and watch it recover.

Consensus tier

Quorum is 2 of 3. Isolate the leader and the survivors elect a new one at a higher term; the old leader steps down when it rejoins. Isolate two and writes stall — correctly, because a minority must never commit.

Add a document

The leader embeds the text, then replicates the vector — never the text. Replica agreement is then bit-exact by construction instead of depending on every machine producing identical floats.
