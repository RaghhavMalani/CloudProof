FLIGHT DECK ORIENTATION
What does this actually do?

      
It runs repeatable stories about agents and distributed systems failing, retrying, and recovering. Move event by event to see why each action happened and whether every safety rule still holds.

      

        
WORKLOADA real-world story, such as a payment or model rollout.

        
EVENTOne meaningful action: append, persist, timeout, retry, or commit.

        
QUORUMThe majority needed before a replicated change is safe.

        
INVARIANTA rule that must never break, such as “charge only once.”

      

      

        EXAMPLE · REFUND RESPONSE LOST AFTER REMOTE COMMIT
        
Agent records effect intent→Provider refunds ₹8,999→Reply disappears→Worker crashes→Runtime reconciles by effect ID

        
The effect identity, semantic snapshot, and workflow cursor survive together. Recovery queries the existing outcome instead of issuing a second refund.
